dismiss (ERR-04 client, D-16). It shows the tool's text and real code name and is never empty or labelled
success (ERR-02/ERR-05 client). A failed step's card shows its stored error, which survives a cleared
banner and a restart (ERR-03, D-17). The plan closes the phase with the remaining static scans and the
full regression gate.

per-step error was never rendered.

line and new static-scan cases, including the scan for 03-05's run-outcome wiring.

  The label sits in a `position="sticky" bottom={0}` box inside a 165 px scrolling card, so text under it

  scrolls with the card. The card size and the sticky label are unchanged.

  banner/Details. No new expand control is added (UI-SPEC S3).

  `UNSEQUENCED_ERROR_SEQ = -1`. It shows until dismissed. After 03-04 every server payload carries seq.
  This branch covers only a failed `getError` request, whose transport message is shown as before
  instead of being silently dropped.
- **Skipped-with-error card opacity (UI-SPEC UA3):** full opacity, so the failure text stays legible.
