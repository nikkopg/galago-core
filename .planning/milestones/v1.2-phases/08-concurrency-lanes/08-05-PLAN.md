<flagged_assumptions>
- Latch shape (Claude's discretion): one field `_laneHalt?: { reason: "failure" | "freeze"; queueId?;
  lane?; at }`. A failure overrides a freeze. The modal is not a latch: it is read live from the
  modal flag and from a STARTED Tool Box row in the dispatch gate, and laneStatus reports it as
  haltReason "modal" when no latch is set.
- Failure-list cap: 8 entries plus an overflow count (D-16 "e.g. 8"). With the flag off the list is
  never appended to, so it is always empty and the banner renders exactly as today.
- Freeze when not BUSY: the server still sets the latch (the UI disables the button when nothing
  runs, UI-SPEC S5). A FAILED state is never downgraded to OFFLINE, so the failure banner stays.
- The freeze refusal text with the flag off is "Parallel lanes are disabled on the server, so
  there are no lanes to freeze." The UI shows it through "Freeze failed — {message}. ..." (08-09).
- `freezeLanes` adds one unauthenticated mutating procedure to a router that has no auth by design.
  It can only stop dispatch (the safe direction), and no procedure other than Start can clear it.
- The milestone Pitfall 22 alert-dedupe Map is not added: after the first failure, the halt bounds
  further failures to the at most 3 steps already in flight, so alert storms are bounded.
</flagged_assumptions>

<objective>
Make every lane fail closed and give the operator the freeze. Any failure, a primary-lane modal,
or the new Freeze lanes action stops new dispatch on every lane without aborting anything. Only an
operator Start re-arms. The first failure, which carries the STACK guid, is kept while later ones
are listed. The run page gets a lane status read model.

Purpose: LAN-05, LAN-06 and LAN-09 are the safety half of lanes. Two tools running at once must
never mean that one keeps moving into a workcell the operator is recovering.
Output: latch, modal gate, freeze, bounded failure list and enqueue-time validation in
command_queue.ts; `freezeLanes` and `laneStatus` on the commandQueue router;
controller/test/laneHalt.test.ts; additive static pins.
</objective>
