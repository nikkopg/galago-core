<objective>
Give the tool page crash-recovery controls. When galago-web restarts while the F.A.S.T. is paused, no queue step
tracks the instrument any more, so the run page shows nothing. The tool page now always shows a "Run Recovery"
card for runControl tool types with Resume and Abort, confirmed in the shared modal and sent through plan 02-04's
`tool.recoveryControl`. While a run step tracks the tool the buttons are disabled with a pointer to the run page.

Purpose: UI-07 (tool-page half) and UI-08 (recovery goes through the same confirmed-send path). Implements D-21
and the UI side of D-23.

Output: `components/tools/RunRecoverySection.tsx`, the recovery target in `controlDecision.ts` and
`hooks/useRunControl.ts`, `closeOnDispatch` on `RunControlConfirmModal`, the mount in `pages/tools/[id].tsx`, tests.
</objective>
