<objective>
Deliver the server side of crash recovery and the step-editor cleanup. A new `tool.recoveryControl`
mutation lets the tool page send Resume or Abort to a tool by id when no queue step is tracking it
(for example after a galago-web restart while the instrument is still paused). It reuses Phase 1's
fail-closed `validateControlRequest`, refuses when the queue's running step is on that tool, logs every
attempt, and has no deadline. Fast `abort`/`resume` leave `commandFields`, so the protocol step editor and
the tool page Send Command form no longer offer them.

Purpose: UI-07 (server half and step-editor half) and UI-08 (single, audited send path on the server).
Implements D-20, D-22 and D-23. The tool-page UI that calls this mutation is plan 02-05.

Output: `controller/server/recoveryControl.ts`, the `recoveryControl` procedure, `test/recoveryControl.test.ts`,
the trimmed `commandFields.fast`, and the inverted Phase 1 D-10 guard in `test/runControl.test.ts`.
</objective>
