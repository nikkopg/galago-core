Exports:
- `FakeGrpc`: an object type whose executeCommand, getStatus, configure, estimateDuration and close are each a vi.fn(). Type them as ReturnType of typeof vi.fn, so the helper works on either approved vitest major.
- `installFakeTool(toolId: string, toolType: ToolType): { tool: Tool; grpc: FakeGrpc }`:
  1. Call Tool.forId(toolId, "127.0.0.1", 1, toolType). This registers the Tool in the real global store and starts its 5 s heartbeat.
  2. Immediately call tool.stopHeartbeat().
  3. Call the original client's close() and ignore its result. grpc-js channels are lazy, so no connection is ever opened.

- `deferred<T = void>()`: returns { promise, resolve, reject, isSettled }. isSettled() reports whether the promise has resolved or rejected, tracked by handlers attached when it was created.
