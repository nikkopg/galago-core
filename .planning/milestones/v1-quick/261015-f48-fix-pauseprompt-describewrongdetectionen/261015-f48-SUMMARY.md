## Decisions Made
- **String `"-1"` sentinel:** Chose to treat the exact string `"-1"` the same as the number `-1`, per the plan's stated discretion. Rationale: `detail` is untyped instrument JSON (typed `unknown`), so a stringified sentinel from the instrument is plausible, and matching is exact (`=== -1` / `=== "-1"`) — no trimming or numeric coercion of arbitrary strings — so no genuine plate ID (including `0` or other negatives like `-2`) is ever hidden from the operator. Documented in a code comment above `isNoPlateDetected`.
