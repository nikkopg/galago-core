<objective>
Make Stop safe while an instrument run is in flight. The queue's stop button (relabelled "Pause queue"),
Clear All and the per-run delete button can all detach a running controllable step today (D-19 research
finding: Clear All deletes the step's rows with no confirmation at all). During such a step each of them now
opens a new InstrumentStopModal: "Abort the instrument run (return liquid? Yes/No)" or Cancel, with no timer
and no default. The queue action runs only after the instrument accepted the abort.

</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → Pause queue / Clear All / delete run | Queue-level actions that, mid-step, can orphan an instrument run physically in progress |
| browser → commandQueue.toolControl then stop/clearAll/clearByRunId | Two sequential mutations whose order is the safety property |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no packages |
| T-02-11 | Denial of Service | Stop/Clear All/delete orphaning a running instrument step (operationally an unsupervised physical run) | high | mitigate | Interception while a controllable step runs; runAfterAccepted runs the queue action only after an accepted abort; "aborts before stopping" asserts call order end to end |
| T-02-12 | Elevation of Privilege | Countdown auto-confirm making the physical decision for the operator | high | mitigate | InstrumentStopModal wraps the shared no-timer, no-default modal; acceptance greps forbid the countdown modal import and timers; re-checked by plan 02-06's static scan |
| T-02-13 | Tampering | Queue stopped or cleared after a refused or failed abort | high | mitigate | followUp runs only on status "accepted"; "a refused abort never stops the queue" and "clear follow-ups" tests |
| T-02-14 | Denial of Service | Deleting an unrelated pending run forcing an instrument abort | low | mitigate | shouldInterceptRunDelete scopes interception to the running step's runId; "run delete interception" test |
