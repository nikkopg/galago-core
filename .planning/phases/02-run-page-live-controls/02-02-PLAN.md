<objective>
Deliver the `tool_paused` prompt. When the instrument pauses itself (for example deck 3 is empty), the run
page opens a prompt within one poll showing the reason ("WrongPlateType (-645)"), the detail in plain
language ("Deck 3: expected plate 1, found none") and when it started. The operator picks Resume or Abort,
which opens the shared confirm modal from plan 02-01. The prompt is driven only by the run-state poll and
never touches the queue's UIMessage machinery, so it can never resolve or block the queue.

Purpose: UI-04 and UI-05. Implements D-10..D-15.

Output: `components/runs/pausePrompt.ts` (pure), `components/runs/ToolPausedModal.tsx`, the prompt state in
`ControlBar.tsx`, and `test/pausePrompt.test.ts`.
</objective>
