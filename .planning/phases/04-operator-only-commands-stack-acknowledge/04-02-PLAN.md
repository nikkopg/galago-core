<objective>
Make operator-only commands unreachable from every non-operator path: one zero-import table
(`server/operatorOnlyCommands.ts`, D-01, D-03, D-04) enforced at the two locked points (D-02) —
(a) execute time at the top of the instance `Tool.executeCommand`, keyed on `String(this.toolType)`,
logging "Operator-Only Command Refused" then throwing `OperatorOnlyCommandError` before any gRPC; and
(b) enqueue time in `RunStore.createFromProtocol`, rethrown (not wrapped) and mapped to a visible
BAD_REQUEST / 400 (OPR-04). `controlCommand` — the operator path — is never guarded.

Purpose: galago-web has no authentication, so "operator-only" means unreachable from any protocol,
script, queue row, editor or direct runCommand call; the table + two enforcement points is the only
mechanism that covers imported JSON, scripts, "Send to Tool" and rows already in SQLite
(ACK-AND-F3.md §2.1 — hiding from `commandFields` is NOT the mechanism).

Output: `server/operatorOnlyCommands.ts`, the two guards, the two error mappings,
`test/operatorOnly.test.ts`.

Task 1 is this plan's tracer: execute-time guard end-to-end through the tRPC runCommand caller with a
stack fake — refusal, audit line, zero gRPC. Task 2 adds the enqueue layer and both error mappings.
</objective>
